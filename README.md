# Idea to Launch Kit · Codex Skill

把 AI 网页产品的点子或 PRD 做成可分阶段验收的 MVP。内含 PRD 模板、开发和部署手册、阶段自检脚本。

## 使用

把本仓库的 `idea-to-launch-kit/` 复制到 `~/.codex/skills/`，然后在 Codex 中调用：

> 使用 $idea-to-launch-kit，读取我的 PRD，先做需求体检，目标是做出本地可运行的 MVP。

[查看 Skill 入口](idea-to-launch-kit/SKILL.md)。启动工程基于 [原项目](https://github.com/hubooooooo/idea-to-launch-kit/tree/3e9bf7a)，按 MIT 许可分发。
